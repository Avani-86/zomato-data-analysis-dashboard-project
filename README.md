# Zomato Restaurant Analysis Dashboard 🍽️

## Project Overview
An interactive web application built with Streamlit 
to analyze Zomato restaurant data and uncover insights 
about customer preferences, cost trends, and ratings.

## Live Features
- 📊 15+ Interactive Visualizations
- 🍴 Restaurant Recommendation System
- 🤖 ML Rating Prediction Model
- 🗺️ Restaurant Location Map
- 🔍 Interactive Filters

## Tools Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Plotly & Altair
- Streamlit
- Scikit-learn (Machine Learning)

## Dataset
Zomato Restaurant Dataset from Kaggle:
https://www.kaggle.com/datasets/shrutimehta/zomato-restaurants-data

## Key Analysis
- Online order vs ratings analysis
- Top 10 cuisines by popularity
- Cost distribution analysis
- Restaurant recommendation system
- ML based rating prediction
